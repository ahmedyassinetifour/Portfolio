# Ahmed Yassine Tifour — Portfolio

## Student name

Ahmed Yassine Tifour

## Project description

I created this responsive personal portfolio website for my ENSTA WAMD HTML, CSS, and JavaScript assignment. It introduces me, presents my skills and real projects, summarizes my education and experience, and provides my contact links.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser DOM APIs

## Implemented features

- Semantic sections for home, about, skills, projects, experience/education, and contact
- Responsive layouts for desktop, tablet, and smartphone screens
- Tabbed project showcase with keyboard navigation
- King of Barber and Fanuna project carousels
- Full-screen image viewer with arrows, counter, keyboard navigation, and close controls
- Project detail dialogs
- Scroll reveal and hover animations
- Accessible focus states, skip link, image alt text, and keyboard controls
- Email, GitHub, and LinkedIn links
